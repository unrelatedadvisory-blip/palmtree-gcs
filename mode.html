PILIH MODE SIMULASI

  • MODE PEMUPUKAN

    Mode lawn mower berjalan memindai lurus pada area jalan setapak dan berpindah jalur secara zig zag (Boustrophedon Path)
  • MODE PENYIANGAN

    Mode lawn mower berjalan mengitari pohon kelapa sawit satu per satu dan berpindah barisan pohon secara zig zag (Boustrophedon Path)
  • MODE CUSTOM WAYPOINT

    Mode lawn mower berjalan memindai mengikuti titik koordinat yang telah dipilih secara manual
